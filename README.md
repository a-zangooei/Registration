## 🎯 معرفی و هدف سامانه

در دوره‌های علوم پایه پزشکی (ترم‌های ۳، ۴ و ۵)، به دلیل تعدد دروس دارای بخش‌های نظری و عملی (آزمایشگاه، کارآموزی و سالن تشریح) و برگزاری امتحانات میان‌ترم حذفی و پایان‌ترم متمرکز، انتخاب واحد سنتی همواره با چالش تداخل ساعات کلاسی و امتحانی و نقض پیش‌نیازها همراه است.

این سامانه به دانشجو اجازه می‌دهد با چند کلیک، وضعیت واحدهای اخذ شده را مدیریت نماید، تداخلات را به صورت بلادرنگ مشاهده کند، ترکیب بدون تداخل را پیدا کند و در نهایت برنامه نهایی را به صورت **PDF رسمی**، **فایل HTML مستقل** یا **عکس باکیفیت (PNG)** ذخیره نماید.

---

## 🌟 ویژگی‌های کلیدی و قوانین آموزشی

### ۱. مدیریت هوشمند سقف و کف واحد
- **تنظیم پویا:** امکان تنظیم کف واحد (پیش‌فرض: ۱۲ واحد) و سقف مجاز (پیش‌فرض: ۱۴.۴۹ واحد برای دانشجویان با معدل زیر ۱۷).
- **محاسبه تفکیکی:** نمایش مجموع واحدهای نظری، عملی، پایه/تخصصی و عمومی به همراه درصد سهم هر دسته.
- **آینده‌نگری انتقال به ترم ۶:** محاسبه خودکار واحدهای باقی‌مانده از چارت درسی که به ترم ششم منتقل خواهند شد.

### ۲. بررسی پیش‌نیازها و هم‌نیازها
- بر اساس قاعده دانشگاهی: کلیه دروس ارائه شده در گزارش، پاس‌نشده تلقی شده و سایر دروس پاس‌شده فرض می‌شوند.
- اگر پیش‌نیاز یک درس در لیست انتخابی نباشد، هشدار عدم رعایت پیش‌نیاز صادر می‌شود.
- اگر دو درس هم‌نیاز باشند، با اخذ یکی، وضعیت لزوم اخذ درس هم‌نیاز بررسی و تذکر داده می‌شود.

### ۳. فیلتر جنسیتی دروس عمومی
- پشتیبانی از تفکیک جنسیتی برادران و خواهران در دروس عمومی معارف (مانند اندیشه اسلامی و دانش خانواده).

## 🔬 منطق هوشمند گروه‌های عملی

دروس دارای بخش عملی (نظیر تشریح ادراری، فیزیولوژی کلیه، انگل‌شناسی، پاتولوژی، قارچ‌شناسی، بافت‌شناسی و...):

1. **حالت پیش‌فرض (بازه‌های شناور - Tentative Slots):**
   - دانشجو مجبور به انتخاب یک گروه عملی در گام نخست نیست.
   - کلیه بازه‌های گروه‌های عملی آن درس در جدول هفتگی با **استایل هاشورخورده (Hatched Pattern)** نمایش داده می‌شوند تا محدوده اشغال کلاس‌ها مشخص باشد.
   - **عدم احتساب تداخل کاذب:** بازه‌های شناور عملی به عنوان تداخل شمرده نمی‌شوند و در یک روز و ساعت مشترک، در کنار هم به زیبایی نمایش می‌یابند چون تصمیم‌گیری نهایی بعداً انجام خواهد شد.
2. **حالت تثبیت گروه خاص:**
   - دانشجو می‌تواند یک گروه عملی مشخص را انتخاب نماید. با این کار، سایر بازه‌های آزمایشی حذف و گروه منتخب با **رنگ یکدست و قطعی** جایگزین می‌شود.

## ⚡ موتور تشخیص تداخلات سه‌گانه

سیستم مجهز به الگوریتم بررسی ریاضی فواصل زمانی `[StartA, EndA)` و `[StartB, EndB)` است:

1. **تداخل ساعات کلاس:** بررسی برخورد بازه‌های زمانی دو درس در یک روز هفته.
2. **تداخل امتحانات میان‌ترم حذفی و پایان‌ترم:** اعلام اخطار قطعی در صورت همزمانی دو امتحان در یک روز.
3. **بررسی بلادرنگ هاور (Hover):** با بردن نشانگر ماوس روی هر درس، دروس متداخل با رنگ قرمز و با انیمیشن ملایم برجسته می‌شوند.

## 📤 ماژول جامع خروجی و گزارش‌گیری (Export Engine)

سامانه دارای ۳ نوع خروجی مستقل، بدون نیاز به سرور و با تجمیع هوشمند کلاس‌های عملی است:

| نوع خروجی | فرمت | ویژگی‌ها |
| :--- | :---: | :--- |
| **PDF رسمی / پرینت** | `PDF / Print` | استفاده از `@media print`، استایل اختصاصی A4 افقی، حذف المان‌های کنترلی و چاپ جدول هفتگی و تقویم امتحانات |
| **فایل وب مستقل** | `HTML` | تولید فایل HTML کامل با استایل‌های درون‌خطی و فونت‌های استاندارد بدون نیاز به اینترنت یا فایل خارجی |
| **عکس یکپارچه** | `PNG` | رندر گرافیکی ۱۶۰۰×۱۴۰۰ پیکسل با HTML5 Canvas، تجمیع بازه‌های عملی شناور و تفکیک رنگی نظری و عملی |

## 📶 معماری ۱۰۰٪ آفلاین (Offline-First)

- **بدون وابستگی به CDN:** تمامی فایل‌ها و استایل‌ها به صورت محلی در باندل نرم‌افزار قرار دارند.
- **تایپوگرافی سیستم و محلی:** استفاده از پشته فونت‌های استاندارد فارسی (`system-ui, -apple-system, Tahoma, Vazir, IRANSans, sans-serif`) برای سازگاری کامل در کلیه دستگاه‌ها بدون مصرف ترافیک اینترنت.
- **سرعت رندر آنی:** تمام ارزیابی‌ها در حافظه مرورگر اجرا می‌شوند.

## 📐 ساختار داده و Schema دروس

هر درس بر اساس الگوی تایپ‌اسکریپت زیر ذخیره و اعتبارسنجی می‌شود:

```typescript
export interface Course {
  id: string;
  code: string;
  name: string;
  term: number; // 3, 4, 5
  category: 'specialized' | 'general';
  units: {
    theory: number;
    practical: number;
    total: number;
  };
  instructors: string;
  theorySchedule: TheorySchedule; // gender-specific or shared slots
  practicalGroups: PracticalGroup[]; // group id, name, slots
  midtermExam?: ExamInfo; // date, notes, isFullDeletion
  finalExam?: ExamInfo; // date, notes
  prerequisites?: string[]; // list of course codes
  corequisites?: string[];
}
```

## 💻 راهنمای نصب و اجرای محلی

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- npm یا pnpm

### مراحل اجرا:

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/your-username/medical-course-scheduler.git
cd medical-course-scheduler

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای سرور توسعه (Local Dev Server)
npm run dev

# ۴. ساخت نسخه نهایی بهینه‌شده برای انتشار (Production Build)
npm run build
```

### 🚀 استقرار خودکار روی GitHub Pages (کاملاً بدون سرور - ۱۰۰٪ رایگان):
این پروژه یک **Single Page Application (SPA)** استاتیک است و برای اجرا **هیچ نیازی به سرور، دیتابیس یا بک‌اند ندارد**. فایل اکشن `.github/workflows/deploy-pages.yml` در پروژه قرار داده شده است.

برای فعال‌سازی:
1. در ریپازیتوری گیت‌هاب خود به تب **Settings** بروید.
2. از منوی سمت چپ گزینه **Pages** را انتخاب کنید.
3. در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** بگذارید.
4. با هر بار `git push` به شاخه `main` یا `master`، برنامه به صورت خودکار بیلد شده و در آدرس `https://<username>.github.io/<repo-name>/` بدون هیچ هزینه‌ای منتشر می‌شود!

### 📱 راهنمای اختصاصی اجرا روی اندروید (Android ARM64 / Termux):
در محیط Termux به دلیل استفاده از کتابخانه `bionic libc` به جای `glibc` و معماری `aarch64`، ماژول‌های کامپایل‌شده‌ی Rust مانند LightningCSS و Tailwind Oxide نیاز به بسته‌های باینری هماهنگ با اندروید دارند که در بخش `optionalDependencies` فایل `package.json` تعریف شده‌اند:

```bash
# ۱. آماده‌سازی بسته‌ها در ترموکس
pkg update && pkg upgrade -y
pkg install nodejs-lts git -y

# ۲. کلون و ورود به پوشه
git clone https://github.com/your-username/medical-course-scheduler.git
cd medical-course-scheduler

# ۳. نصب وابستگی‌ها
npm install

# در صورت مواجهه با خطای عدم یافتن lightningcss.android-arm64 یا oxide-android-arm64:
npm run termux:setup

# ۴. اجرای برنامه
npm run dev
```

پس از اجرای `npm run dev`، سامانه در آدرس `http://localhost:3000` در دسترس خواهد بود.
